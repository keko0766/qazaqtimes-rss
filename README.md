# GeoNewsBot

GeoNewsBot — macOS-та жергілікті ашылатын жаңалық құралы. Ол RSS/GDELT деректерін жинап, SQLite-ке сақтайды, дайджест жасайды және қазақша мақала жобаларын дайындайды.

## Қосу

`GeoNewsBot.app` файлын екі рет басыңыз.

App өзі:

- жергілікті GUI ашады;
- Ollama бар-жоғын тексереді;
- `gpt-oss:20b` моделін тексереді;
- модель жоқ болса, оны background-та жүктейді және GUI-де прогресс көрсетеді.

Ollama орнатылмаған болса, GUI мына хабарды көрсетеді:

`Ollama орнатылмаған. ИИ үшін Ollama қажет.`

Сол жердегі `Ollama жүктеу бетін ашу` батырмасы ресми жүктеу бетін ашады. App өзі орнатпайды және әкімші құпиясөзін сұрамайды.

## Күнделікті жұмыс

1. `GeoNewsBot.app` ашыңыз.
2. GUI ашылған соң `Бүгінгі мақалаларды жасау` батырмасын басыңыз.
3. Нәтижелер `Бүгінгі мақалалар` және `Соңғы дайджест` бөлімдерінде көрінеді.

ИИ дайын болмаса, мақала fallback режимімен жасалады. Ollama және модель дайын болғаннан кейін келесі генерацияда `gpt-oss:20b` қолданылады.

## Деректер

Деректер мына жерде сақталады:

```text
~/Library/Application Support/GeoNewsBot/
```

Құрылымы:

```text
data/news.sqlite3
output/
runtime/app.log
runtime/ollama_status.json
```

Нәтиже app жабылып қайта ашылғаннан кейін де сақталады.

## Шектеулер

- онлайн API қолданылмайды;
- API key қажет емес;
- толық мақала мәтіні жүктелмейді;
- автожариялау жоқ.
